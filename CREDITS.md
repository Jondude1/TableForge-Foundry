# Credits

Carried over from the TableForge app (`Jondude1/TableForge-web`), whose look
was put together from D&D / TTRPG interface designs found through Pinterest's
"DnD UI" and "DnD app" boards. Pinterest pins point back to the original
makers, so these are credited at the source. No artwork, code or assets were
copied from these projects — they shaped the palette, type choices and a few
interaction patterns, which are reimplemented from scratch.

## Fonts

The app bundles **Cinzel** and **Crimson Text** (SIL Open Font License 1.1).
This Foundry module does not bundle them — it uses a system serif stack in
the donor's palette instead (see SPEC.md).

## Icons

Interface icons are Font Awesome (as provided by Foundry VTT) and, on the
maps board, the device's system emoji font — the same approach as the app.

## Game content

Generated ideas follow D&D 5th Edition conventions (rarities, attunement,
DCs). Dungeons & Dragons is a trademark of Wizards of the Coast; TableForge
is an unofficial fan tool and is not affiliated with or endorsed by Wizards
of the Coast.
